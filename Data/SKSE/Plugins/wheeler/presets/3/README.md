# Preset 3: Dark Medieval

A dark ages aesthetic with iron gray and leather tones. Weathered and rugged, but still crisp and readable.

## Visual Style
- **Slot Shape**: Arc (radial segments)
- **Colors**: Iron gray, dark leather, rust accents
- **Feel**: Dark ages, weathered, rugged

## Key Features
- Deep shadows for dramatic depth
- Iron-colored border ring
- Heavy text shadows (3-layer)
- Dark semi-transparent backgrounds
- Slower, more subtle hover pulse
- Corner decorations on center panel

## Settings Changed
- WheelRadius: 290px (medium-large)
- SlotShape: Arc (0)
- InnerRadiusRatio: 0.52
- IconSize: 100px
- UseSkyrimTheme: false (uses custom dark colors)
- SlotShadowAlpha: 120 (deeper shadows)
- TextShadowLayers: 3 (full 8-direction shadow)

## Activation
Set `ActivePreset = 3` in `[Presets]` section of AmmoWheel.ini, or use the dMenu preset selector.

## Fallback Behavior
Uses the default AmmoWheel blue theme as base, with heavy shadow effects for the dark medieval feel.
