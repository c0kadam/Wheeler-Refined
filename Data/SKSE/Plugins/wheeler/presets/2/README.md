# Preset 2: Modern Minimal

A clean, new-gen HUD aesthetic with circle slot shapes and high contrast.

## Visual Style
- **Slot Shape**: Circle
- **Colors**: Clean whites/grays with subtle blue accent
- **Feel**: Modern, minimal, crisp

## Key Features
- Circle slots for a contemporary look
- No decorative border (clean edges)
- No slot shadows (flat design)
- High contrast text with dark background
- Subtle hover highlight
- Minimal animations

## Settings Changed
- WheelRadius: 260px (medium)
- SlotShape: Circle (3)
- InnerRadiusRatio: 0.45
- IconSize: 80px
- UseSkyrimTheme: false
- BorderEnabled: false
- SlotShadowEnabled: false
- TextShadowEnabled: false

## Activation
Set `ActivePreset = 2` in `[Presets]` section of AmmoWheel.ini, or use the dMenu preset selector.

## Fallback Behavior
Uses the default AmmoWheel blue theme colors when Skyrim theme is disabled.
