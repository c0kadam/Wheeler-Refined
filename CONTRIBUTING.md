# Contributing to Wheeler Refined

Thank you for helping improve Wheeler Refined. Contributions should target this project's stability, features, compatibility, documentation, or developer tooling rather than unrelated changes to original Wheeler.

## Before You Start

- Read [BUILDING.md](BUILDING.md) and verify a no-deployment Release build when changing code.
- Search existing issues and pull requests before opening a duplicate.
- For a significant behavior or API change, open an issue first so scope and compatibility can be discussed.

## Branches and Pull Requests

- Work on a focused branch and open a pull request against `main`.
- Keep each pull request limited to one coherent change.
- Explain the motivation, test method, runtime used, input-device relevance, and compatibility impact.
- Include screenshots or focused logs when they help reviewers verify the result.
- Do not commit generated DLLs, PDBs, logs, caches, dependency checkouts, or build directories.

## Bug Reports

Use the repository issue forms. A useful report includes exact Wheeler Refined, Skyrim, SKSE, and dMenu versions; reproducible steps; relevant UI/input/combat mods; and `wheeler.log` or a complete crash-log attachment when applicable.

## Attribution and Third-Party Material

Preserve existing copyright notices, Wheeler attribution, `LICENSE`, `NOTICE.md`, `THIRD_PARTY_NOTICES.md`, and files under `LICENSES/`. Do not bundle third-party source, fonts, images, or other assets unless their provenance is documented and their terms are compatible with distribution in this repository.
